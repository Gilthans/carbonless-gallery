# Radio checks

This file is saved with Windows line endings (CRLF).

Every morning the bridge does a radio check with the coast radio on channel 16.

## Order

1. The bridge calls the coast radio.
2. The coast radio answers with signal strength.
3. The bridge logs the check in the vessel log.

## If there is no answer

Try channel 12, then channel 10. If there is still no answer, the shift lead calls the office by phone.
