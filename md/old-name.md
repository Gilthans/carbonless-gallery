# Port codes

Every port has a three-letter code used in the timetable export and on tickets.

| Port | Code |
|------|------|
| Strandkaien | STK |
| Nordnes | NRD |
| Askøy | ASK |
| Kleppestø | KLP |

Codes never change once issued. A new port gets the next free code that the
national register hasn't already given to another operator.

The codes are printed on every ticket, under the departure time.
