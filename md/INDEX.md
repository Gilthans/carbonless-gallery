# Tidewater docs: Markdown showcase

Made-up documents for a made-up ferry operator. Each file shows one kind of
Markdown change; the pull request's description says what to look for.

| File | Shows |
|------|-------|
| [text.md](text.md) | Paragraph edits: words, sentences, splits, joins, moves |
| [lists.md](lists.md) | Bullets, ordered lists, nested items, task lists |
| [tables.md](tables.md) | Rows, columns, headers, alignment |
| [code.md](code.md) | Fenced, indented and inline code |
| [structure.md](structure.md) | Headings, sections, blockquotes, rules, folds |
| [inline.md](inline.md) | Links, references, autolinks, footnotes, strikethrough |
| [special.md](special.md) | Front matter, HTML, math and mermaid (shown as source) |
| [images.md](images.md) | Changed, unchanged, remote and removed images |
| [whitespace.md](whitespace.md) | Re-indents, trailing spaces, blank lines, tabs |
| [new-file.md](new-file.md) | A new document |
| deleted-file.md | A deleted document |
| [renamed.md](renamed.md) | Renamed from `old-name.md`, unchanged |
| [renamed-and-edited.md](renamed-and-edited.md) | Renamed from `draft.md`, edited |
| [notes.md](notes.md) | Renamed from `notes.txt`: now Markdown |
| [CHANGELOG.MARKDOWN](CHANGELOG.MARKDOWN) | An upper-case `.MARKDOWN` extension |
| [crlf.md](crlf.md) | CRLF line endings |
| [no-final-newline.md](no-final-newline.md) | No newline at the end of the file |
| [huge.md](huge.md) | Over 512 KiB: Text only |
